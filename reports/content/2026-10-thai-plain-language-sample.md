## Style guide (ร่าง)

1. **ศัพท์เทคนิคใช้ภาษาอังกฤษ ถ้าวิศวกรไทยพูดกันแบบนั้น** เช่น command line, path, log, editor,
   debug, incident, security, snapshot, backup, option, default, parent, shell, terminal.
   ศัพท์ที่ไทยใช้กันจนชินแล้วให้คงไว้ เช่น ไดเรกทอรี, ไฟล์ตั้งค่า, ชุดทดสอบ.
   ห้ามแปลศัพท์ที่ผู้เรียนต้องเอาไปค้นต่อ เช่น "บรรทัดคำสั่ง" ให้ใช้ "command line" แทน
2. **ประโยคสั้น หนึ่งประโยคมีความคิดเดียว** ประโยคที่ยาวเกินและต่อกันด้วย "ซึ่ง ... ที่ ... และ" ให้แยกเป็นหลายประโยค
3. **ห้ามแปลสำนวนอังกฤษตรงตัว** เช่น "sink in" → ~~ซึมเข้าไปในหัว~~, "career-ending" → ~~จบอาชีพ~~,
   "lives up to its reputation" → ~~สมกับชื่อเสียงของมัน~~, "muscle memory" → ~~ให้นิ้วจำ~~
   ถ้าภาษาไทยมีสำนวนที่ตรงกันอยู่แล้วให้ใช้สำนวนไทย เช่น "สมคำร่ำลือ", "ดาบสองคม", "ติดมือ"
4. **เรียกผู้เรียนว่า "คุณ" ตรงๆ แต่ไม่ต้องใส่ทุกประโยค** ประโยคภาษาไทยละประธานได้ตามธรรมชาติ
5. **ลดคำว่า "มัน" ที่ใช้แทนสิ่งของหรือคำสั่ง** ให้ใช้ชื่อสิ่งนั้นซ้ำหรือละประธานแทน
6. **ลด passive แบบแปล ("ถูก...")** เขียนเป็นประโยค active แทน ยกเว้นความหมายเชิงลบที่ภาษาไทยใช้ "ถูก" อยู่แล้ว
7. **ตัดคำเชื่อมแบบแปล** เช่น "นั่นคือส่วนที่...", "...เสียอีก", "ไม่ว่าเจตนาจะเป็นอย่างไร", "พูดแบบตรงไปตรงมา"
8. **ห้ามเปลี่ยน**: ความหมายและข้อเท็จจริง, คำสั่ง, code block (รวม comment ในโค้ด), ชื่อไฟล์/path,
   `checkpoint` (คำถามและคำตอบ), ข้อความภาษาอังกฤษทั้งหมด และส่วนคำสั่งใน `try.steps`
   ข้อความภาษาไทยในวงเล็บท้ายคำสั่งใน step ก็ยังไม่แตะในตัวอย่างนี้ (ดูคำถามข้อ 2)

| paragraph 1 | Git ติดตามโฟลเดอร์หนึ่งเมื่อคุณสั่งให้มันติดตาม จากวินาทีนั้นโฟลเดอร์จะมีไดเรกทอรีซ่อนชื่อ .git ที่เก็บประวัติทั้งหมดไว้ และทุกอย่างที่คุณทำเกิดขึ้นบนเครื่องตัวเอง — ไม่ต้องมีบัญชี ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องมีเครือข่าย | Git จะติดตามโฟลเดอร์ก็ต่อเมื่อคุณสั่ง หลังจากนั้นโฟลเดอร์จะมีไดเรกทอรีซ่อนชื่อ .git ไว้เก็บประวัติทั้งหมด และทุกอย่างทำบนเครื่องคุณเอง — ไม่ต้องมีบัญชี ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องต่อเน็ต |

## คำถามถึง founder

1. **อนุมัติแนวทางนี้ไหม** — ถ้าโอเค จะเกลาข้อความภาษาไทยของทั้งสองคอร์สตาม style guide ข้างบน
   (ยังไม่แตะ `checkpoint`, code, คำสั่ง และข้อความภาษาอังกฤษ)
2. **ข้อความภาษาไทยใน code block และใน `try.steps`** เช่น `# สร้างไดเรกทอรี` หรือ `(ดูก่อนลบ — เรียงลำดับแบบนี้เสมอ)`
   ตอนนี้ไม่ได้แตะเพราะการ์ดห้ามแก้ code ข้อเสนอของทีมคือให้เกลาเฉพาะส่วนที่เป็นภาษาไทยหลังเครื่องหมาย `#` หรือในวงเล็บ
   และไม่แตะตัวคำสั่งเลย ข้อความส่วนนี้สั้นอยู่แล้วและอ่านเข้าใจได้ จึงจะไม่แก้ก็ได้
3. **ระดับการใช้ศัพท์อังกฤษ** — ตัวอย่างนี้เปลี่ยน "บรรทัดคำสั่ง" เป็น command line, "ภาพถ่าย" เป็น snapshot,
   "เหตุการณ์ด้านความปลอดภัย" เป็น security incident ถ้า founder อยากให้ไทยมากกว่านี้ ก็ปรับ style guide ข้อ 1 ได้
