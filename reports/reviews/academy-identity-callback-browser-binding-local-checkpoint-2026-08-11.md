## Outcome

Academy's local authorization transaction now carries a separate browser
binding. The begin boundary returns one raw opaque binding to its server caller
and stores only its SHA-256 digest. The callback must present the same binding
before the transaction store releases PKCE, nonce, client configuration, or the
return path.

A malformed or different binding returns fixed `browser_mismatch`, calls no
assertion provider or exchange adapter, and leaves a live transaction available
for the browser that started it. A correct binding claims the transaction once.
Expiry still removes the transaction durably.

## Transaction Contract

- `beginIdentityAuthorization` generates a 32-byte binding and returns it only
  beside the existing server-side verifier result.
- `PendingIdentityTransaction` stores a 43-character base64url SHA-256 digest,
  never the raw binding generated by the begin boundary.
- memory and file stores reject malformed or mismatched bindings before deleting
  a live transaction;
- comparison uses fixed-size digest bytes and Node's captured
  `timingSafeEqual`;
- the file store performs read, binding check, one-time deletion, and write
  under the existing exclusive lock;
- both concrete stores accept only exact own enumerable data fields for the
  transaction and nested client, then persist a fresh projection rather than
  retaining caller objects or surplus fields;
- a digest is accepted only when decode and base64url re-encode return the same
  canonical 32-byte SHA-256 value;
- a second live transaction with the same state is rejected atomically, and a
  persisted file containing duplicate states is rejected without rewrite;
- the local file schema advances to version 2; version 1 and malformed digest
  files fail closed without rewrite;
- correct binding after a mismatch still succeeds once, including after a new
  file-store instance opens the same state.

The file store remains a restart-test reference. Cloudflare runtime wiring must
use a released durable Academy persistence boundary rather than the local file.
